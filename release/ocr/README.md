# 可选离线 OCR 包

文件名：`Tesseract-5.5-zh-en.ocrpack.zip`

用途：在系统没有 Windows OCR、或需要独立离线 OCR 的机器上，从应用“设置 → 导入 OCR 包”导入。

内容：

- Tesseract 5.5 x64
- 简体中文 `chi_sim.traineddata`
- 英文 `eng.traineddata`
- 全部运行文件和模型清单
- 逐文件 SHA-256 校验
- 256 MB 解压体积上限

大小：6.60 MiB

SHA-256：

```text
9A92566F10D7BC24D20BDEF973C5DD981A09A1FBAF623A23BA077910C293011C
```

来源与许可：

- Tesseract / TesseractOCR 5.5.2：Apache-2.0
- Leptonica 1.85.0：BSD-2-Clause
- `tessdata_fast` 中文、英文模型：Apache-2.0

该包是可选项，不包含在 3.58 MiB 的基础安装包中。
