# 纸坞 UI · v5 Fluent 定稿

已选定 Windows 原生方向。设计参考 Fluent 2，已在 `app/` 中实现为 WPF 界面。

## 页面

| 文件 | 内容 |
| --- | --- |
| `split.png` | 拆分：4 页预览、拆分方式、输出类型、单主操作 |
| `merge.png` | 合并：文件顺序、前 4 页预览、输出名 |
| `convert.png` | Word / Excel / PPT 转换与限制说明 |
| `settings.png` | 系统 OCR、离线 OCR 包、输出默认值 |

## 设计规则

- 左侧导航固定四项：拆分、合并、转换、设置。
- 蓝色只用于当前导航、选中状态和唯一主按钮。
- 水印、输出目录、完成后打开目录收进“更多选项”。
- 默认只展示 4 页，避免一上来铺满所有内容。
- 设置页不显示未安装能力，也不自动下载 OCR 包。
- 不支持的功能不显示入口。
- 正文 11–13px，标题 20–27px，主按钮 46px 高。

| 角色 | 值 |
| --- | --- |
| 主色 | `#0F6CBD` |

| 次级文字 | `#5D6873` |
| 边框 | `#DFE4EA` |
| 圆角 | 6–9px |

WPF 实现时优先使用系统控件与键盘焦点，不把静态网页控件一比一硬画。

注意：WPF 内置 `ThemeMode` 需要 .NET 9+；本项目当前选择 .NET Framework 4.8，需用资源字典实现这套 Fluent 外观，不能直接套用 .NET 9 的 Fluent 主题。
源文件为 `index.html`，通过 `?view=split|merge|convert|settings` 切换。
