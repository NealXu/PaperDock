安装包结构曾经完成一次静默安装、安装目录启动和静默卸载。最终重建后的未签名安装包被本机应用控制策略阻止，未能再次执行；因此正式分发前必须代码签名或在企业策略中放行。便携 ZIP 内容与 `dist` 逐文件哈希一致，但解压到新目录后同样受本机应用控制策略限制。

## 四、已知边界

1. 未在 Windows 10 实机验证。
2. 未验证 100%/125% 显示缩放；本机 150% 缩放可用。
3. 安装包未签名，本机应用控制策略会拦截新的未签名安装器。
4. Word/Excel 不承诺复杂版式还原；PPT 为整页图片。
5. 系统 OCR 的中文精度受页面清晰度和字体影响。
